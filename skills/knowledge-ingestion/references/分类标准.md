# 分类标准

碎片归类到哪本书、哪个章节的判断依据。

## 归类流程

```
提取碎片中的核心实体（工具名/项目名/领域词）
  → 匹配现有书的标签
    → 有匹配：归入对应书，找最接近的章节
    → 无匹配：放入待分类区
```

## 提取实体的优先级

1. 工具名：OpenCode、Claude、GitHub、Prompt Market 等
2. 项目名：Prompt Market、游戏素材工具、播客等
3. 领域词：AI编程、写作、产品设计、内容创作等
4. 抽象主题：效率、变现、人设、学习方法等

如果多个实体指向不同书，选出现频次最高的那个。

## 章节匹配

碎片归入某本书后，匹配已有章节标题。匹配不上就在书中新建一个章节，章节名从碎片的核心结论中提取。

章节名规则：用名词性短语，不用完整句子。比如「坐标系转换」而不是「我踩了一个坐标系转换的坑」。

# 扩展判断指南

判断一条知识条目是否值得扩展成完整文章的标准和操作指引。

## 判断流程

```
信息量足够吗？
  ├─ 否 → 不扩展
  └─ 是 → 有个人经历吗？
              ├─ 否 → 不扩展
              └─ 是 → 有情绪钩子吗？
                          ├─ 否 → 不扩展
                          └─ 是 → 跟已有内容重复吗？
                                      ├─ 是 → 不扩展，建议合并（注明原文章）
                                      └─ 否 → 扩展 ✓
```

## 什么值得写

- 有具体场景和数字的（"花了3天""日活从100掉到20"）
- 有情绪转折的（"以为很简单，结果……""本来想放弃，然后……"）
- 有独特视角的（跟主流观点不一样，或者很少有人提的角度）
- 有可执行建议的（读者看完可以照着做）

## 什么不值得写

- 只有感慨没有细节
- 纯新闻/资讯转述（没有你的看法和经历）
- 太常见的观点（"AI很重要""要多学习"）
- 信息量不足以撑起500字以上的内容

## 扩展建议模板

如果判断为值得扩展，给出以下信息：

1. 开头方式：怎么切入（个人经历/热点事件/承接前文）
2. 主体结构：先讲什么后讲什么
3. 可用素材：条目中哪些细节可以展开
4. 预计字数：500-800/800-1500/1500-2500

# 🎯 wechat-title · 公众号爆款标题生成

#### 22 个「篇篇10W+」头部账号的标题方法论，封装成一个可复用的 AI Skill

[Agent Skills](https://agentskills.io/) 开放标准 · 适配 Claude Code / Codex / OpenCode 等 40+ Agent

---

## 这是什么

一个**基于真实爆文样本**的标题生成 Skill。不是拍脑袋的"16 条标题公式"，而是把 22 个篇篇10W+头部公众号（覆盖 7 大内容领域）的真实标题逐条拆解，提炼出**领域级方法论 + 可套用模板库 + 自检清单**三件套。

### 为什么值得用

**样本真实。** 全部方法论来自 22 号真实标题样本（每号 20-30 条，共 500+ 条），代表例句均为原句，不是编的。

**按领域分类。** AI 读者看热闹，商业读者找利益，健康读者求答案，人物读者买情绪——同一个公式跨领域套用必然失败。本 Skill 按 7 个领域分别沉淀方法论，每个领域对应一组头部账号的实测经验。

**有自检体系。** 生成后过 10 条自检清单（爆点前置、数字佐证、广告法禁区、悬念兑现、长度控制…），帮你提前砍掉废标题。

## 适合什么

| ✅ 适合 | ❌ 不适合 |
|---|---|
| 给公众号文章起标题（7 大领域全覆盖） | 长文写作（那是 khazix-writer 的活） |
| 标题共创 / 多候选 A/B 测试 | 小红书/推特等短内容平台标题 |
| 已有标题的优化与 A/B 备选 | 纯标题摘要生成（仅提取文章要点） |
| 想学习头部账号的标题套路 | 需要标题数据统计报告 |

## 怎么触发

```
帮我的文章起几个标题
这篇文章用爆文风格起标题
标题共创：我写了篇关于XX的文章
帮我优化这个标题
给标题出 10 个 A/B 候选
```

## 怎么用（三步）

1. **丢内容**：把文章正文、提纲或一句话主题发给 AI
2. **AI 执行**：自动完成"领域分类 → 定调 → 套模板 → 自检 → 输出"五步
3. **你挑选**：从 Top 3 + 备选池里挑，或让 AI 按反馈再出一轮

> 生成前，AI 会先读对应领域的完整方法论文件（references/），保证出手就有该领域的地道感。

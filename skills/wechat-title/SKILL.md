# 公众号爆款标题生成

> **"标题不是玄学，是统计学。"**
>
> 这个 skill 的每一句方法论，都来自 22 个「篇篇10W+」头部公众号的真实标题样本。代表例句均为样本原句，未经改写。完整方法论见 references/ 目录。

## 设计理念

**先分类，再套方法论，最后自检。** 不同领域的读者点开标题的动机完全不同——AI 读者看热闹，商业读者找利益，健康读者求答案，人物读者买情绪。同一个标题公式跨领域套用必然失败。所以这个 skill 把方法论按 7 个领域分开沉淀，每个领域对应一组头部账号的实测经验。

**你只需要两步：告诉我内容，告诉我你希望读者点开后的感觉。**

## 工作流程（五步）

```
用户给内容（文章/提纲/一句话主题）
  ↓ 第1步：分类——判断内容所属领域（下表）
  ↓ 第2步：定调——匹配该领域的"风格账号"（个人号亲历流 or 媒体号新闻流 or 观点流…）
  ↓ 第3步：套模板——按内容类型选择对应句式模板，生成 8~12 个候选标题
  ↓ 第4步：自检——过一遍禁忌清单与通用检查项，剔除废标题
  ↓ 第5步：输出——推荐 Top 3，并说明每个标题用的手法与适用场景
```

## 第1步：领域分类

| 内容信号 | 领域 | 代表账号 |
|---|---|---|
| 模型/产品发布、AI评测、Agent、编程、科技公司动态、参数/成本数字 | AI科技 | 卡兹克、卡尔、量子位、机器之心、新智元 |
| 创业、商业模式、公司分析、管理认知、老板视角、市场格局 | 商业 | 半佛仙人、刘润、兽楼处、笔记侠 |
| 股市/大盘、行业涨跌、政策经济、投资判断、企业财报 | 财经 | 财经早餐 |
| 个人成长、职场、副业赚钱、认知升级、习惯自律、情感共鸣 | 成长职场 | 粥左罗、进击的阿秀、张良计、栩先生、S叔Spenser、古典古少侠、十点读书 |
| 读书、书单、人文典故（金庸/红楼等）、人生哲理、美文 | 文化读书 | 六神磊磊、洞见、书单来了 |
| 身体症状、生活习惯、饮食运动、医学科普、育儿健康 | 健康 | 丁香医生 |
| 名人特稿、群体处境、时代观察、深度故事 | 人物 | 人物 |

判断要点：按「内容主角 + 读者利益」双信号定领域；拿不准时，问自己"读者点开是为了什么——看热闹/学方法/防踩坑/找共鸣"，再映射到表。

## 第2步：定调（跨领域通用的人设二分）

- **个人号风格**（卡兹克/卡尔/粥左罗/S叔/六神磊磊）：第一人称亲历叙事，卖"我替你先试了/我先想明白了"。适合评测、经验复盘、观点输出。
- **媒体号风格**（量子位/机器之心/新智元/财经早餐/丁香医生）：新闻紧迫感，卖"你还没看到"。适合热点、发布、资讯、干货转载视角。
- **观点流**（半佛/张良计/洞见）：锐评或金句，卖"认知反差与情绪共鸣"。适合评论、观点文。
- **特稿流**（人物/兽楼处）：留白极简，卖"时代情绪与故事悬念"。适合深度故事、人物。

## 第3步：领域核心规律与模板速查

> 每个领域只列最核心的规律与高频模板。完整方法论（逐号风格速查、全部模板、反模式）见 references/ 对应文件，生成前如时间允许先读该文件。

### AI科技（完整版 → references/methodology-ai.md）

- 双段式骨架：`{悬念/情绪段}！{信息/爆点段}`——逗号/感叹号/冒号切两刀
- 数字是第一燃料：资源量级（54小时/20亿Token）、场景清单（10个）、对比反差（57.1倍/半价/碾压）
- 人名=免费流量：奥特曼、黄仁勋、Karpathy 直接入题
- 个人号卖"亲历验证"，媒体号卖"新闻紧迫"
- 高频模板：`刚刚，{产品}{动作}了！` / `实测{产品}，{效果}——{数字}` / `烧了{资源}后，我找到了{方法}` / `{公司}急了：{冲突信息}！` / `{产品A}碾压{产品B}`
- 禁忌：绝对化预言慎用；技术名词≤2个；"实测"必须有数字；爆点放前15字

### 商业（完整版 → references/methodology-business.md）

- 认知反差+利益点：`真正的{资源}，不再是{旧概念}，而是{新概念}`
- 疑问句三变体：荒诞问（"是不是疯了？"）/留白反问（"万一…怎么办"）/求知问（"为什么突然爆火？"）
- 大咖背书：`{权威}最新{访谈}：{一句话核心观点}`；数字量化：`{数字}个{对象}，{结果}，怎么做到的?`
- 高频模板：`{大咖}最新{访谈|长文|对话}：{紧迫判断}` / `{对象}，是不是疯了？` / `没有{人物}的{数字}年`
- 禁忌：空泛口号；"最/第一/保证赚到"踩广告法；标题党割裂正文；点名攻击个人

### 财经（完整版 → references/methodology-health-person-finance.md）

- 数字是信任货币：14季度、200亿、39个分析师——每字带信息
- 事件必须配判断：`{事件}，{主体}要{反转词}了？`——回暖/见底/重新认识
- 引号圈新词自带传播："抢铜潮""老登股"
- 高频模板：`{数据}，{主体}要{反转词}了？` / `{不起眼事物}，凭什么{惊人收益}？` / `{现象}背后，{主体}的{冷思考}`
- 禁忌：纯事实无判断；荐股腔（"必翻倍"）；超25字无断句

### 成长职场（完整版 → references/methodology-growth.md）

- 最通用结构：`{人群标签} + {痛点} + {转变/指令}`——"31岁二胎宝妈…""女人最通透的活法"
- 转变叙事+数字实证：`从{惨起点}到{好结果}，{具体数字}：{一句话方法}`
- 反常识断言驱动转发："怂，才适合赚大钱"；热点借势：`{热点人物}：{一句与我相关的人生教训}`
- 人称策略：你（对话感）/他（标签群像）/我（亲历背书）；引号造概念：「4分认知+6分莽撞」
- 高频模板：`{人群}，{痛点}，怎么办？` / `永远不要{行为}` / `最{形容词}的{名词}：{观点}` / `说句得罪人的话：{锐评}`
- 禁忌：说教感（"你们应该"必死，换成"我发现"）；无受众的空洞鸡汤；超30字前15字必须有利益点

### 文化读书（完整版 → references/methodology-culture.md）

- 经典符号×当下议题嫁接（最高效）：`{经典人物/作品} + {当下事件/痛点} + 冒号观点`
- 观点前置：`再看《{作品}》我顿悟：{颠覆认知的结论}`
- 数字清单定锚：`{数字}本/N件事`；金句排比：`任何{关系}到最后：{动1}的是{名1}，{动2}的是{名2}`
- 高频模板：`{经典人物}{事件}：{出人意料的当下观点}` / `人到{阶段}以后，比{省钱}更重要的是{更高层价值}`
- 禁忌：掉书袋过头；严肃符号戏谑；鸡汤无落点；"最"字滥用

### 健康（完整版 → references/methodology-health-person-finance.md）

- 先问症再给出口：钩子=读者能对号入座的身体/生活细节，不是医学名词
- 反常识是最高级手段："毁牙第一名！不是可乐而是它"；恐吓与安抚必成对
- 数字承担确定性："4种表现""2岁后一定要试试"；括号截断术吊悬念
- 高频模板：`{症状}？有{数字}种情况不及时处理，小心{永久后果}` / `你以为{正常}，实则是{疾病}的{数字}种表现`
- 禁忌：生僻医学名词当钩子；纯恐怖无安抚；空泛"健康十大建议"

### 人物（完整版 → references/methodology-health-person-finance.md）

- 标题是时代之问而非答案：`{群体}，{一种怎样的处境}？`
- 先时代后个体；卖情绪不卖信息；反差并置即张力（"姚晨 狼狈的人，现实中人"）
- 高频模板：`当{群体}开始{动作}` / `{大事件}过后，{群体}的{处境/行动}` / `{时间/季节}，一边{情绪A}，一边{情绪B}`
- 禁忌：标题剧透结局；信息轰炸；恐吓/利益承诺腔

## 第4步：自检清单（生成后逐条过）

1. 爆点前置：前 15 字内必须出现最大钩子（数字/人名/冲突/人群标签）
2. 数字佐证：出现"实测/亲测/最"时必须能对应正文具体数字，否则删
3. 禁止项：明示"最/第一/保证"收益承诺（广告法）；空泛口号；纯恐吓无安抚
4. 悬念兑现：标题承诺的钩子正文必须有对应答案
5. 长度控制：≤30 字（成长逆袭叙事可放宽到 35，但前 15 字必须有利益点）
6. 感叹号密度：一条标题最多 1 个感叹号（新智元式双叹只用于突发新闻）
7. 领域一致性：标题手法必须来自第1步判定的领域方法论，禁止跨领域乱套
8. 人群明确：成长/健康/人物类标题必须有可对号入座的人群或场景坐标
9. 是否引用真实热点：人名/事件必须是真实存在的，禁止虚构人名蹭流量
10. 二次传播性：问自己"读完标题，读者愿意截图转发吗"

## 第5步：输出格式

```
【领域】成长职场｜【定调】个人号亲历流
【Top 候选】
1. 推荐标题A —— 手法：{人群标签+转变叙事}，适用：主标题
2. 标题B —— 手法：{热点借势}，适用：备选/次条
3. 标题C —— 手法：{反常识断言}，适用：备选
【备选池】其余候选列出（每行一条，不解释）
【已剔除】说明剔除原因（对应禁忌条款）
```

## 高级技巧：融合策略

- 同一内容生成 3 个方向：情绪向（共鸣/惊讶）、利益向（数字/方法）、悬念向（留白/反转），再各取最佳
- 个人号内容可叠加媒体号框架："实测X，{刚刚发布}供参考"——亲历+时效双钩
- 长文（>2000字）用逆袭叙事/深度叙事标题；短文/资讯用突发/清单标题；干货文用大咖背书或数字清单

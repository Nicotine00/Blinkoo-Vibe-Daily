# 榨知机.skill · 把对话榨成素材

## 核心机制

每次对话结束后，自动扫描本轮全部内容，把你自己的结论性思考摘出来。不是你问了AI什么，是你在对话过程中形成的、属于你自己的思考成果。

摘出来后，AI先自检质量，达标才入库。不达标直接扔。

## 捕获什么

主要捕获你在对话中形成的五类思考成果：

| 类型 | 是什么 | 示例 |
|------|--------|------|
| 判断 | 你做出了选择或下了结论 | A方案快但维护成本高，选B方案 |
| 洞察 | 你想通了一个之前没明白的事 | 用户要的不是功能多，是功能可预期 |
| 决策 | 你决定怎么做 | 以后都先plan再动手 |
| 反思 | 你发现自己之前想错了 | 之前觉得Electron好，现在看来太重了 |
| 提炼 | 你从信息中抽出了自己的理解 | AI协作的关键不是模型，是你的指令质量 |

没有以上信号就不产生碎片，跳过本轮。宁可漏也不要误收。

## 质量自检（AI必须过）

每一条碎片在入库前，AI必须自检以下五项，全部通过才保存：

1. 这是用户自己的结论，不是复述AI的回答
2. 内容具体，有场景或细节支撑，不是空泛的感悟
3. 带有用户的判断或态度，不是中性的事实陈述
4. 用户今后回头看会觉得有用，不是一时兴起的废话
5. 能用一句话说清核心，不是散装的流水账

一项不通过就舍弃。标准极高，宁少勿滥。

## 唯一露面的时候

你平时感觉不到它的存在。它只在你每次对话结束后出现，输出一句话：

提取了2条碎片，归到开发经验 → 技术决策

或者：

本轮未提取有价值的思考成果，跳过。

不啰嗦，不刷屏。你知道它工作了就行。除此以外它不主动说任何话。

## 查看素材

任何时候想看积累进度，说 看看我的榨知机 或 我的素材库：

```
📚 你的素材库

开发经验（12条）
├── 技术决策（4条）
├── 协作方法（5条）
└── 安全与规范（3条）

写作方法论（10条）
├── 技巧体系（4条）
├── 标题与开头（3条）
└── 风格演变（3条）

产品思考（3条）
└── 产品与市场（3条）
```

想看某个主题详情，说 打开开发经验：

```
# 开发经验

## 技术决策
- 判断 A方案快但维护成本高，选B方案更稳
- 决策 以后都先plan再动手
- 洞察 用户要的不是功能多，是功能可预期

## 协作方法
- 提炼 交叉审查多个模型方案优于单模型
- 提炼 修bug三步法
- 提炼 验收标准三问
```

## 与上次对话的衔接

下次开新对话时，榨知机自动加载所有主题的素材册，让AI知道你的立场、判断和结论。不需要手动翻文件，不需要说帮我看看之前聊了什么。

## 三件事

第一件事是喂回给AI。下次新对话AI自动加载素材，知道你的立场和判断。

第二件事是分类归档。所有摘出来的碎片自动归类到对应主题的方向下。

第三件事是素材沉淀。同一主题的碎片自动累积到同一份文件中，方向越来越充实。

## 输出目录

```
juice/
├── books/
│   ├── 开发经验.md       # 按主题汇编，每条带日期
│   ├── 写作方法论.md
│   ├── 产品思考.md
│   └── ...
└── run-log.md
```

每个主题一个文件，打开就是完整的素材汇总，不需要翻几十个碎片文件。

## 没有终点

没有完成概念。它一直跑，永远在收，永远在分。

## 如何使用

安装：把榨知机.skill 放到你的 skill 目录，告诉 AI 加载，首次指定 juice/ 目录位置。

日常：正常聊天。每次对话结束自动输出一句话摘要。

查看：说 看看我的榨知机 或 打开[主题名]。

## 用户职责

1. 首次使用时指定 juice/ 目录位置
2. 碎片级别无需任何操作

## 注意事项

- 不要编造用户没说过的话。只摘用户自己形成的结论
- 质量自检不过的碎片直接丢弃，不进文件
- 去重时宁可保留两条相似也不要错误合并
- 从不主动在对话中推任何内容，只在你问的时候展示

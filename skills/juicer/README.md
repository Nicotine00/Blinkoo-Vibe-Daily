# 🍋 榨知机 · 把对话榨成素材

#### 自动捕获对话中你形成的结论性思考，精炼去重后按主题汇编成册

[Agent Skills](https://agentskills.io/) 开放标准 · 适配 Claude Code / Codex / OpenCode 等 40+ Agent

---

## 这是什么

一个**自动积累个人知识资产**的 Skill。每次对话结束后，自动扫描本轮全部内容，把你**自己形成的**判断、洞察、决策、反思、提炼摘出来，AI 先自检质量，达标后按主题归档到素材册。下次新对话自动加载相关记录，AI 一开始就知道你的立场和结论。

### 为什么值得用

**捕获的是你的思考，不是对话记录。** 不是你问了 AI 什么，是你在对话过程中形成的、属于你自己的结论。每条记录都按"案例分析"格式保留完整推理链条——别人读完能复现你的推理过程，而不只是看到结论。

**宁少勿滥。** 每条入库前过 6 项质量自检，不达标直接丢弃。素材册里只有真正值得回看的结论。

**自动衔接。** 下次新对话时自动加载所有主题素材册，AI 知道你的立场、判断和结论，不用手动翻文件。

## 适合什么

| ✅ 适合 | ❌ 不适合 |
|---|---|
| 在对话中形成了自己的结论/决策/洞察 | 记录 AI 给出的答案（那是笔记，不是素材） |
| 想积累个人知识资产但没记录习惯 | 需要全文对话存档 |
| 长期用 AI 协作（写代码/写作/研究） | 一次性咨询场景 |
| 想沉淀自己的方法论体系 | 需要隐私加密存储 |

## 怎么触发

```
榨汁 / 榨知机 / 榨一下
记录结论 / 存一下
我的素材库 / 看看我的榨知机 / 素材库
打开[主题名]  （如：打开开发经验）
```

对话结束时自动执行，不需要手动触发。

## 怎么用（三步）

1. **首次安装**：把 `榨知机/` 目录放进 Agent 的 skills 目录，告诉 AI 加载，首次指定 `juice/` 目录位置
2. **日常使用**：正常聊天，每次对话结束自动输出一句话摘要（"提取了2条碎片，归到开发经验 → 技术决策"）
3. **查看进度**：说「看看我的榨知机」看树状目录；说「打开[主题名]」看某个主题的完整素材

## 捕获什么（五类思考成果）

| 类型 | 是什么 | 示例 |
|------|--------|------|
| 判断 | 你做出了选择或下了结论 | 比较了 Cursor 和 OpenCode，结论：长期项目用 OpenCode |
| 洞察 | 你想通了一个之前没明白的事 | 分析后台数据发现：堆功能不如保核心 |
| 决策 | 你决定怎么做 | 踩坑后决定：每次新任务前先查 Git 状态提交基线 |
| 反思 | 你发现自己之前想错了 | AGENTS.md 只能管通用规则，不同项目需要单独的 skill |
| 提炼 | 你从信息中抽出了自己的理解 | 交叉审查法：90% 情况下第二模型能补第一个漏掉的关键点 |

## 质量自检（入库前必过）

1. 是用户自己的结论，不是复述 AI 的回答
2. 包含完整上下文（背景+过程+结论）
3. 内容具体，有真实场景或案例支撑
4. 带有用户的判断或态度
5. 三个月后回头看依然能看懂、觉得有用
6. 一个条目只讲一件事；没有内部代号，任何外部读者都能看懂

一项不通过就舍弃。标准极高，宁少勿滥。

# 瞭望台（Project Watchtower）

> 跨 AI 会话的项目互通 skill：一个状态仓库 + 一份全局规则，让同时进行的多个 AI 项目互相看得见进度。
> 兼容 opencode / Claude Code / WorkBuddy 等任何认 markdown 与 AGENTS.md 的 AI 客户端。

## 它解决什么

每个 AI 会话只有一次对话的记忆。同时开 N 个项目时：A 项目想用 B 项目的进展当素材，只能重启 B 项目挨个问；
上次聊过的结论，下次对话全忘。瞭望台把这个缺陷补成：**所有会话共享同一份最新动态**，且零代码、零服务。

## 安装（约 3 分钟）

### 第 1 步：建状态仓库

```
project-states/
├── _TEMPLATE.md        # 新建项目复制用（见下方模板）
├── README.md           # 机制说明 + 项目表（本文件或其精简版）
└── <你的项目名>-status.md   # 每项目一个
```

模板（`_TEMPLATE.md`）：

```markdown
# <项目名>：<一句话定位>

## 当前任务
- 任务描述（完成度 %）

## 最近进展
- 2026-08-13：完成 xxx（结果一句话）

## 阻塞 / 等待
- （没有就写"无"）

## 下一步
- （接下来 1-3 件事）
```

### 第 2 步：写全局规则

在 AI 客户端的全局指令文件（opencode 为 `~/.config/opencode/AGENTS.md`，Claude Code 为 `~/.claude/CLAUDE.md`，WorkBuddy 为 `~/.workbuddy/AGENTS.md`）加入：

```markdown
## 跨项目互通（强制）
1. 对话开始时：列出 <STATE_DIR> 下所有 *-status.md，逐文件读，向用户汇报每个项目的「当前任务 + 最近进展」
2. 每完成一个关键任务：更新 <STATE_DIR>/<本项目>-status.md（最近进展保留 3-5 条）
3. 没去过的项目：写「待该会话更新」，禁止编造
```

`<STATE_DIR>` 换成你的状态仓库真实路径（跨盘符共享时放公共盘根目录，如 `F:\project-states\`）。

### 第 3 步：接入每个项目

对每个项目执行一次：复制 `_TEMPLATE.md` 为 `<项目名>-status.md` 填入定位；在项目根的 AGENTS.md 末尾追加一行：

`每完成关键任务，更新 <STATE_DIR>/<项目名>-status.md`

## 日常使用

- **让 AI 汇报**：说「瞭望台」或「看看其他项目进度」——AI 会按本 skill 汇报全部项目 + 健康摘要
- **标记含义**：✦ 活跃（≤7 天）/ ⚪ 停滞（8-30 天）/ 🪦 失联（>30 天）/ 🧩 占位（机制未激活）
- **加新项目**：让 AI 读本 skill 的「新建项目接入」节自动执行

## 可选增强

- `关联索引.md`：项目间「谁该读谁」矩阵，适合项目群有依赖关系（如素材工具→游戏→公众号）的场景
- 部署副本：多 AI 客户端共用时，把 skill 目录复制到各客户端的 skills 路径，主源唯一
